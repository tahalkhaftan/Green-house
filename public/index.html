داده‌ها و روش شبیه‌سازی

دادهٔ پایه از فایل بازنشرشدهٔ مسابقهٔ گلخانهٔ خودکار تهیه شده است. دادهٔ اولیه از یک گلخانهٔ بزرگ است و رفتار گلخانهٔ ۲×۲×۳ متری با یک مدل ساده و قابل تنظیم تخمین زده می‌شود.

شبیه‌سازی BLE و RS‑485 در این نسخه یک مدل احتمالی آموزشی است. محاسبهٔ درصد دریافت بر اساس دادهٔ فیزیکی اندازه‌گیری‌شده از گلخانهٔ تو نیست. نمایش گیاه شاخص تصویری است و بیماری واقعی را تشخیص نمی‌دهد.

مدل PyTorch دمای یک ساعت بعد را بر اساس چهار نمونهٔ پنج‌دقیقه‌ای پیش‌بینی می‌کند. خطا روی بخش پایانی داده جداگانه گزارش می‌شود.

ذخیرهٔ داخل سایت در مرورگر انجام می‌شود. برای نگه‌داری بیرون از مرورگر فایل JSON را دریافت کن. اجرای GitHub Actions می‌تواند نتایج اجرای خودکار را در مخزن ذخیره کند.
