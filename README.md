# Green-house | آزمایشگاه گلخانهٔ هوشمند

شبیه‌سازی آموزشی یک گلخانهٔ گوجهٔ ۲×۲×۳ متر با ساعت شتاب‌پذیر برای یک تا پنج سال، نمای سه‌بعدی، پنج حسگر، تجهیزات، مقایسهٔ ارتباط سیمی و بی‌سیم و پیش‌بینی دما با PyTorch. کاربران می‌توانند دادهٔ ساعتی تمام مدت اجرا و آخرین بسته‌ها را به JSON دریافت کنند.

## اجرا

نسخهٔ ساخته‌شده در `public/` قرار دارد. نیازمندی‌ها Python 3.10+ و Node 20+ هستند.

```bash
pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 4173
# در مرورگر: http://127.0.0.1:4173
```

برای توسعه و بررسی:

```bash
npm ci
npm test
npm run build
node scripts/run_batch.js
```

## داده و حد اطمینان

- `public/weather-2021-2025.json`: **۴۳٬۸۲۴ ساعت پیوسته** دما، رطوبت نسبی، تابش کوتاه‌موج، باد و بارش برای تهران در سال‌های ۲۰۲۱ تا ۲۰۲۵، با زمان محلی تهران. [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api) از داده‌های بازتحلیل استفاده می‌کند؛ این‌ها مشاهدهٔ حسگر گلخانه نیستند. محل و سال، سناریوی نمونه‌اند و به معنای شرایط امروز نیستند. مختصات شبکه، واحد و نشانی دریافت در خود فایل آمده است.
- آزمایش از اول ژانویهٔ ۲۰۲۱ شروع می‌شود و برای یک تا پنج سال از داده‌های پشت‌سرهم استفاده می‌کند؛ سال کبیسهٔ ۲۰۲۴ با ۳۶۶ روز لحاظ می‌شود و دادهٔ سال‌ها تکرار نمی‌شود. زمستان، بهار، تابستان و پاییز به‌ترتیب تاریخ نشان داده می‌شوند. از آنجا که هوای واقعی هر فصل روی تراز حرارتی و نور اثر دارد، مصرف تجهیزات و پاسخ بوته‌ها در فصول متفاوت است. کشت گوجه فقط به یک فصل محدود نیست؛ رقم و مدیریت تعیین‌کننده‌اند.
- گلخانه و گیاه **شبیه‌سازی ساده و کالیبره‌نشده** هستند: محاسبهٔ آزمایشی تراز گرمای محسوس، رطوبت هوا، ذخیره و برداشت آب، تابش، VPD، رشد و تنش است. تغییرات بیماری، آفات، مراحل رشد زیستی، برداشت و ترکیب مواد غذایی مدل نشده‌اند. نتیجه برای تصمیم‌گیری عملی یا ادعای نرخ خطا/مرگ واقعی کافی نیست. برای نتیجهٔ قابل اتکا باید پارامترها با حسگرها و تجهیزات واقعی و آزمایش مستقل کالیبره شوند.
- برای کنترل دما، آستانه‌های فرضی روشن و خاموش شدن بخاری در روشنایی ۱۸ و ۲۱ درجه و در تاریکی ۱۶٫۵ و ۱۹ درجهٔ سانتی‌گراد است؛ فن و سرمایش آبی در دماهای بالاتر فعال می‌شوند. [دانشگاه کنتیکت](https://ipm.cahnr.uconn.edu/wp-content/uploads/sites/3216/2022/12/2017pollinationofgreenhousetomatoes-1.pdf) اهمیت دما و رطوبت در گوجه را توضیح می‌دهد؛ نیاز رقم و مرحلهٔ رشد فرق می‌کند. برای سهولت، رشد شبیه‌سازی‌شده بیرون از بازهٔ انتخابی متوقف می‌شود. مدل مرگ یک شاخص تنش قراردادی است، نه تشخیص زیستی قطعی.
- منابع فنی بیشتر: [مرور علمی دما و رطوبت گلخانهٔ گوجه](https://www.ars.usda.gov/ARSUserFiles/20200500/Pubs%202018/Shamshiri2018%20-%20review%20optimum%20microclimate%20greenhouse.pdf)، [Alabama Cooperative Extension: تولید گوجهٔ گلخانه‌ای](https://www.aces.edu/blog/topics/crop-production/greenhouse-tomato-production/). تنظیمات pH حدود ۵٫۵ تا ۶٫۵ و EC محلول ۲ تا ۲٫۵ mS/cm از منبع دوم گرفته شده‌اند. مقادیر pH و EC در این برنامه **ورودی فرضی و ثابت محلول** هستند؛ EC بستر یا تغییرات واقعی شیمی محلول محاسبه نمی‌شود.
- پارامترهای فرضی: ظرفیت حرارتی مؤثر ۶۰۰ kJ/K، ضریب اتلاف ۳۵ W/K، فن ۳۰۰ m³/h، بخاری ۱۵۰۰ W، مخزن ۳۰ L، بستر ۴۰ L و مرحلهٔ زمانی ۵ دقیقه. نرخ تعرق، اتلاف، روشنایی مصنوعی، سرمایش و مرگ فقط تقریب هستند. سرمایش آبی در دسترس بودن آب را فرض می‌کند و حداکثر کاهش هوای ورودی ۷°C در مدل قراردادی است، نه مشخصات یک محصول واقعی.
- مدل ظاهری بوته از [Caged Tomato Plant](https://tevy.dev/models/caged-tomato-plant) با مجوز CC0، به‌صورت glTF و با بافت استفاده شده است. اگر WebGL در دسترس نباشد نمای دوبعدی جایگزین نشان داده می‌شود.

## ارتباط و سناریوی خرابی

یک کنترل‌کنندهٔ مرکزی فرض شده است؛ در سامانهٔ واقعی، هر حسگر بی‌سیم باید خودش فرستنده و منبع تغذیهٔ مناسب داشته باشد. BLE و RS‑485 در این پروژه شبیه‌سازی کامل پروتکل یا لایهٔ فیزیکی نیستند. هر دو مسیر مقادیر یکسان تولیدشده را با مدل احتمالاتی فرضی و حداکثر سه تلاش منتقل می‌کنند. این مدل نویزِ اندازه‌گیری، خطای بیت کشف‌نشده، تأیید/خطای CRC واقعی، اثر کانال رادیویی واقعی و جزئیات سخت‌افزار را شبیه‌سازی نمی‌کند. انتخاب مسیر صرفاً بر مبنای این درصدها نتیجهٔ علمی نیست.

کلید قطع کامل هر مسیر، دریافت و اعتبار داده‌های همان مسیر را فوراً قطع می‌کند و پس از اتصال مجدد، کنترل‌کننده منتظر نمونهٔ تازه می‌ماند. اسلایدر ترافیک یا تداخل روی ۱۰۰٪ باعث قطع کامل همهٔ پیام‌های جدید بی‌سیم در این سناریوی قراردادی می‌شود. کنترلر تا سه دوره داده را تازه می‌داند؛ سپس برای مشاهدهٔ اثر خرابی، آخرین وضعیت تجهیزات را نگه می‌دارد. دکمهٔ «آزمایش قطع ارتباط با بخاری روشن» بخاری را روشن و داده‌ها را قطع می‌کند و اگر شاخص تنش به مرگ برسد، ساعت متوقف می‌شود. **نگه داشتن بخاری روشن یک سیاست نمایشی ناایمن است و برای سخت‌افزار واقعی مناسب نیست.**

## مدل PyTorch

`ml/train.py` با چهار نمونهٔ پیاپی ۵ دقیقه‌ای دما، رطوبت، CO₂ و نور، تغییر دمای یک ساعت بعد را پیش‌بینی می‌کند. آموزش و تقسیم زمانی روی بازنشر دادهٔ [مسابقهٔ گلخانهٔ واگنینگن](https://huggingface.co/datasets/Okyanus/greenhouse-sensor-data) انجام شده، نه روی دادهٔ تهران یا خروجی این مدل. بنابراین خطای گزارش‌شدهٔ آزمون به داده‌های گلخانهٔ دیگر تعلق دارد و به این سناریو تعمیم داده نشده است. وزن‌های صادرشده در `public/model.json` بدون نیاز به PyTorch در مرورگر ارزیابی می‌شوند.

گردش‌کار `Train greenhouse PyTorch model` در GitHub Actions داده را دریافت و مدل را روی CPU آموزش می‌دهد. آموزش فعلی جای کالیبراسیون فیزیکی یا اعتبارسنجی پیش‌بینی روی گلخانهٔ کوچک تهران را نمی‌گیرد.

## نگه‌داری داده‌ها

خروجی JSON کل اجرای ساعتی شامل محیط، مقادیر تحویلی مسیر انتخابی، سن داده‌ها، وضعیت تجهیزات و شاخص گیاه را نگه می‌دارد. ریز بسته‌ها به آخرین ۱۲ تا ۱۳ هزار رکورد محدود است؛ هنگام ذخیرهٔ مرورگر آخرین ۵۰۰ رکورد بسته نگه داشته می‌شود، ولی سری ساعتی کامل می‌ماند. دکمهٔ ذخیره، داده‌ها را فقط در همان مرورگر نگه می‌دارد و دکمهٔ JSON فایل مستقل می‌دهد. گردش‌کار دستی `Run greenhouse comparison` یک سناریوی مستقل تا پنج سال یا مرگ ایجاد و در `results/runs/` ذخیره می‌کند؛ اجرای مرورگر خودکار به GitHub فرستاده نمی‌شود. دیسک سرویس رایگان Render ذخیره‌سازی دائمی نیست.

## حرکت و اَبَرسریع

فن، روشنایی زرد بخاری و آب‌پاش با وضعیت تجهیزات هماهنگ‌اند. نمایش خط‌چین‌های آبی داده و خط‌چین‌های قرمز ترافیک و تداخل از جعبهٔ «نمایش مسیر امواج بی‌سیم» فعال می‌شود. این خطوط یک تصویر مفهومی از جهت ارتباط هستند، نه شبیه‌سازی الکترومغناطیسی. گزینهٔ «اَبَرسریع» محاسبه را در دسته‌های کوتاه اجرا می‌کند تا توقف همچنان پاسخ‌گو باشد؛ محاسبه در زمان مرگ متوقف می‌شود.

شبیه‌سازی پنج‌ساله ادامهٔ همان مدل سادهٔ بوته است و برداشت، تعویض بوته، پیری زیستی و طول عمر واقعی محصول در آن مدل نشده‌اند.
