# Green-house | شبیه‌ساز گلخانهٔ هوشمند

یک گلخانهٔ گوجهٔ ۲×۲×۳ متری، یک ESP32 مرکزی و پنج سنسور. رابط فارسی، داده‌های محیط، رشد و پژمردگی قابل مشاهده، کنترل فن و آبیاری، مقایسهٔ سیمی و بی‌سیم و پیش‌بینی دما دارد.

## اجرا

نیازمندی‌ها Python 3.10+ و Node.js 20+ هستند. فایل رابط آماده در `public/` قرار گرفته است.

```bash
pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 4173
```

صفحهٔ `http://127.0.0.1:4173` را باز کنید. برای توسعهٔ رابط `npm ci` و سپس `npm run build` را اجرا کنید.

## داده، هوش مصنوعی و محدودیت‌ها

- `public/trace.json` شامل ۱۶۸ نمونهٔ ساعتی انتخاب‌شده از بازنشر فایل `agc2_reference.csv` در [Hugging Face](https://huggingface.co/datasets/Okyanus/greenhouse-sensor-data) است. منبع اولیهٔ گزارش‌شده، دادهٔ [مسابقهٔ گلخانهٔ خودکار واگنینگن](https://research.wur.nl/en/datasets/autonomous-greenhouse-challenge-second-edition-2019/) و مجوز بازنشر CC BY 4.0 است. بازنشر مزبور فایل‌های مصنوعی و تغییرشکل‌یافته نیز دارد. مسیر، تبدیل‌ها و منشأ فایل پیش از استنتاج علمی نیازمند بررسی نسخهٔ اصلی است.
- سری زمانی مربوط به گلخانهٔ بزرگ است. مدل اقلیم، رشد و شاخص سلامت در این پروژه تقریب آموزشی برای یک گلخانهٔ کوچک است. رطوبت خاک در دادهٔ پایه نیست و شبیه‌سازی می‌شود. وضعیت گیاه تشخیص پزشکی، بیماری یا تضمین برداشت نیست.
- `ml/train.py` با PyTorch چهار نمونهٔ پیاپی ۵ دقیقه‌ای را برای پیش‌بینی دما در یک ساعت بعد به کار می‌برد. تقسیم آموزش/اعتبارسنجی/آزمون زمانی و به‌ترتیب ۷۰/۱۵/۱۵ است. خطای آزمون و مبنای «بدون تغییر دما» در `models/metrics.json` هستند. مدل در مرورگر با وزن‌های صادرشده اجرا می‌شود و برای استقرار به نصب PyTorch نیازی نیست.
- مدل شبکه به‌صورت احتمالی و با پارامترهای فرضی اجرا می‌شود. BLE و RS‑485 در این نسخه شبیه‌سازی فیزیکی یا پیاده‌سازی کامل پروتکل نیستند. برای نتیجهٔ علمی لازم است احتمال خطا، تأخیر، نرخ قطع و اثر انسداد با سخت‌افزار واقعی کالیبره شوند.
- هر دو پیوند یک جریان دادهٔ سنسور یکسان دریافت می‌کنند. هر بار تا دو تلاش دوباره انجام می‌شود. مقایسهٔ درصد دادهٔ سالم انجام شده است. دادهٔ کنترلر بر اساس مسیر انتخابی است و دادهٔ قدیمی علامت می‌خورد.
- داده‌های اجرای سایت در مرورگر کاربر ذخیره و با دکمهٔ JSON قابل دریافت است. دیسک رایگان Render دائمی نیست. برای ذخیره در مخزن، گردش‌کار `Run greenhouse comparison` را دستی در GitHub Actions اجرا کنید تا `results/runs/` ثبت شود. این اجرا از اجراهای تعاملی سایت مستقل است.

## آموزش در GitHub Actions

گردش‌کار `Train greenhouse PyTorch model` پس از تغییر فایل‌های `ml/` یا با اجرای دستی شروع می‌شود، فایل دادهٔ عمومی را می‌گیرد، مدل را روی CPU آموزش می‌دهد و وزن JSON و معیار آزمون را به شاخهٔ اصلی می‌فرستد. GitHub Actions باید مجوز نوشتن محتوا داشته باشد. استقرار Render با تغییر مخزن دوباره اجرا می‌شود.

```bash
python ml/prepare.py
python ml/train.py
node scripts/run_batch.js
npm test
```

سرعت «۵ ساعت در یک ثانیه» روی زمان شبیه‌سازی اعمال می‌شود، نه روی مقادیر احتمالی هر بسته. درصدهای نشان‌داده‌شده اندازه‌گیری واقعی نیستند.
